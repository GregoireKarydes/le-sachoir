# Tâche du soir : les Grands Dossiers

Objectif : toujours **4 Grands Dossiers dans la file d'attente** `stock/dossier/` (un est publié chaque jour). Depuis le 8 novembre 2026, un dossier n'est plus écrit pour une date : il entre dans la file, GitHub Actions le dessine jusqu'à 100 %, puis la publication du matin le pioche (voir `prompts/STOCK.md`, « Où écrire »).
Lire d'abord : `prompts/CHARTE.md`, `prompts/SCHEMA.md` et `prompts/STOCK.md` (catalogue des thématiques, règles d'alternance, règles d'écriture du Grand Dossier, emplacement dans la file).

## Étapes
1. `git pull`. Compter les dossiers en file : `ls stock/dossier`. S'il y en a 4 ou plus, ne rien écrire. Si un dossier est bloqué (`"blocked"` dans son `item.json`), le débloquer d'abord comme dit dans `prompts/STOCK.md`.
2. Écrire les dossiers manquants pour revenir à 4, **au plus 2 par passage** (un Grand Dossier demande beaucoup de recherche : mieux vaut deux dossiers soignés que trois bâclés).
3. **Choisir les sujets ensemble** pour bien les varier : jamais le même pôle que le dossier précédent de la file (le plus récent de `stock/dossier/`) ni entre les deux nouveaux ; une thématique pas avant les 20 derniers dossiers ; un sujet de Grand Dossier pas avant 12 mois (chercher dans `editions/` et `stock/` avec `grep -r`) ; environ 3 sur 4 liés à la France ; de grands sujets connus et importants, vus dans leur ensemble (« La guerre froide », « Les rois de France », « Les atomes »). (La publication évite d'elle-même de mettre le même jour deux BD du même pôle quand la file le permet.)
4. Pour chaque dossier : recherche web et sources fiables, écriture selon la charte et `prompts/STOCK.md` (**24 cases dessinées au plus**, environ 3 min, quota d'images oblige, chapitres adaptés au sujet, compréhension d'abord, humour dosé, cliffhanger en case 4, `theme` exact), avec 2 à 4 cases « Pour mieux comprendre » (`kind: "explain"`, texte seul, aucune image : elles ne comptent pas dans les 24 cases dessinées) et le champ `story` « L’histoire complète » (150 à 250 mots), 1 à 3 **cases photo** (`kind: "photo"`, vraie image Wikimedia Commons sous licence libre, dont une dans les cases 1 à 4 si possible), le **`teaser`** pour la newsletter, fact-check en seconde passe. Les cases 1 à 4 sont la partie gratuite (et visible sur la page publique quand le paywall est actif) : elles doivent donner envie de lire la suite.
5. Écrire `stock/dossier/<AAAAMMJJ-HHMM>-<mot-cle>/item.json` (`{"added": …, "formats": [ le dossier ]}`, voir `prompts/STOCK.md`). Valider le JSON. Commit « File dossier : <titre> », `git pull --rebase`, `git push origin main` **aussitôt**, avant de passer au dossier suivant.
